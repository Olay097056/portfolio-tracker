# Portfolio Builder presets and ETF Comparison copy are written originally, not reused from stockvision-app

`stockvision-app`'s `bundle.js` self-describes as "Exact replication of doohoon.net features, UI components, sliders, and calculators." The compounding math (DCA/dividend-yield formulas) is generic financial arithmetic and carries no copyright risk. But the curated content — Portfolio Builder's three preset allocations (names, ratios, descriptive copy) and ETF Comparison's per-ETF description text — is specific, authored content that the file's own comment claims is an exact replica of a third-party commercial product. Following the same policy already applied to wethaiinvest.com earlier in this project (describe features in our own words, never copy exact content/branding), these two features get freshly written descriptions and independently-constructed presets in portfolio-tracker. Public facts (ticker symbols, AUM figures, inception dates) are kept since they aren't anyone's copyrightable expression.
