## บั๊กที่ต้องแก้ (`frontend/src/components/tools/TradeDeskDashboard.tsx`)

**1. บรรทัด 70 — MTD แสดงค่าผิดฟิลด์**
```
MTD: {F.pct(team.weekly_target_pct,false)} / 5–20%
สัปดาห์นี้: {F.pct(team.weekly_kpi_pct,false)} / เป้า {F.pct(team.weekly_target_pct,false)}
```
`MTD` เอา `weekly_target_pct` (เป้ารายสัปดาห์) มาแสดงเป็นผลงานรายเดือน แล้วบรรทัดถัดไปใช้ฟิลด์เดียวกันเป็น "เป้า" อีกรอบ
→ ต้องใช้ผลงานเดือนนี้จริง **ถ้า backend ยังไม่คืนฟิลด์นั้น ให้เพิ่มใน `build_state`** — ห้ามเอาฟิลด์อื่นมาแสดงแทนเพื่อให้มีตัวเลข

**2. บรรทัด 72 — ตัวนับเทิร์นฮาร์ดโค้ด**
```
เทิร์น: ✓{team.turns_today} ✗0 ⏳0
```
`✗0` (ล้มเหลว) และ `⏳0` (ค้าง) เป็นเลขศูนย์ตายตัว ไม่ได้มาจากข้อมูล
→ ดึงของจริง หรือถ้ายังไม่มีข้อมูล **ให้เอาออก** — ห้ามแสดงศูนย์ปลอม (หลักโปรเจค: ไม่มีข้อมูล → "—" ไม่ใช่ 0)

**3. บรรทัด 59 — อันดับฮาร์ดโค้ด**
```
<span ...>#1</span>
```
user ตัดสินแล้วว่า **1 ทีม เลิกเรื่องแข่ง** → อันดับไม่มีความหมาย **เอาป้ายนี้ออก**
(อยู่ใน Out of scope ของ map แล้ว — ไม่ใช่การ "แก้ให้ถูก" แต่คือ "เอาออก")

## เกณฑ์ว่าเสร็จ

- MTD แสดงผลงานเดือนนี้จริง หรือแสดง "—" ถ้ายังไม่มีข้อมูล — **ห้ามแสดงตัวเลขที่ไม่ใช่สิ่งที่ label บอก**
- ไม่มีตัวเลขฮาร์ดโค้ดเหลือในการ์ดทีม
- เทสต์ครอบ: MTD ใช้ฟิลด์ถูก · ไม่มีข้อมูล → "—" · ไม่มีป้ายอันดับ
- user เปิดหน้าจริงแล้วยืนยันว่าตัวเลขตรงกับความจริง
