## Question

3 จุดที่ต้อง user ตัดสินก่อนทำ:

1. **ออฟฟิศ 3D** (`/office`) — 3D engine (แผนก 11 + ตัวละคร + กล้องบิน + งานระบบล่าสุด + คิวงานถัดไป) — feasibility บน React+Vite ($0): Three.js? react-three-fiber? หรือตัดเป็น 2D แผนผัง? หรือ out of scope?
2. **บทเรียน** (`/learn`) — เนื้อหา 7 บท + อภิธาน: คัดลอกเนื้อหา reference ตรงๆ (ลิขสิทธิ์?) หรือเขียนใหม่ด้วยหัวข้อเดียวกัน
3. **Telegram** (`/settings`) — ต้องสร้าง bot จริง (ส่งแจ้งเตือนโมเดล/สัญญาณ) หรือ mirror UI อย่างเดียว (ไม่มี push)

## วิธีทำ

- นำเสนอตัวเลือก + ข้อดี/ข้อเสีย + ต้นทุนประมาณ (เวลา/เงิน) — ให้ user ตัดสินสั้นๆ (ก/ข/ค)
- ตัวเลือกที่ตัดสิน → อัปเดต map (ใน/นอก scope) + แตกใบ task ตาม

## Answer

3 การตัดสินครบ (2026-08-11):

1. **ออฟฟิศ 3D** → **ทำ 3D เต็มรูปแบบด้วย Three.js** (user ตัดสิน — ยอมรับงานใหญ่ + dependency ใหม่)
2. **เนื้อหาบทเรียน** → **เขียนใหม่เอง** — โครงสร้าง 7 บท + ไอคอนเหมือน reference, เนื้อหาเป็นของเรา (DeepSeek ช่วยเขียน + ตรวจเอง — ไม่ละเมิดลิขสิทธิ์)
3. **Telegram** → **ตัดออกจากแผน** — settings แสดงแค่บัญชี + รูปแบบการแจ้งเตือน (ไม่สร้าง bot)

→ แตกเป็นใบ 11 (task: learn/settings/office)
