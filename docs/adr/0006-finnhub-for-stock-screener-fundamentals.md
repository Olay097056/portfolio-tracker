# Stock Screener fundamentals come from Finnhub, not FMP or yfinance alone

The Stock Screener's original design (external agent draft, `.gemini/antigravity/brain/.../prompt_draft.md`) called for Financial Modeling Prep as the sole data source, using `/stable/company-screener` to discover the ~10,000+ US ticker universe and per-symbol endpoints for fundamentals. Testing that plan live against the project's own FMP key found both bulk-discovery endpoints locked behind a paid plan (`/v3/stock/list` → 403 "Legacy Endpoint", `/stable/company-screener` → 402 "Restricted Endpoint") — FMP's free tier changed after the draft was written and no longer supports this use case at all; only single-symbol `/stable/quote` still works, and its 250-calls/day cap can't cover a multi-thousand-ticker universe regardless. yfinance, the project's other existing provider, has no bulk discovery endpoint either and would need pairing with a separate ticker-list source, plus its unofficial/scraped nature carries real rate-limit risk at this volume (already hit 429s once this project). Finnhub was evaluated live instead: its free tier's `/stock/symbol?exchange=US` returns the full ticker list in one call, `/stock/metric?metric=all` covers nearly every fundamental ratio the screener needs (PE, PEG, PS, PB, ROE, margins, D/E, beta, dividend yield), `/stock/profile2` gives per-ticker industry classification, and it carries no daily call cap — only a 60-calls/minute throttle, which a full ~4,960-ticker refresh (NASDAQ+NYSE+AMEX common stock, chosen over including OTC to keep the universe to exchange-listed names) comfortably fits inside a single multi-hour offline run. The one gap: `/stock/price-target` (needed for the originally-planned "upside % to analyst target") is paid-tier-only on Finnhub too, so that field was redefined rather than faked — it now holds "Analyst Consensus %", a real value computed from the free `/stock/recommendation` endpoint's buy/hold/sell counts, not a price-target upside. `backend/scripts/refresh_screener.py` was rewritten around Finnhub end to end, removing the hash-based per-field fabrication, synthetic ticker padding, and forced-minimum overrides the FMP-era script had used to paper over its own missing/locked data.
