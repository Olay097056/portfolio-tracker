## Answer (user-confirmed 2026-08-09)

1. **ชุดตัวแปร: ครบ 11 ตัวตามต้นฉบับ** — และเพิ่ม scorer ให้ 3 ตัวที่ตอนนี้เป็น dead keys (sofrSpreadBps, debtPts, fedBps) ใน scoring engine เพื่อให้ลากแล้วขยับจริงทุกตัว
2. **วิธีป้อนค่า: ตามต้นฉบับเป๊ะ** — ค่าส่วนต่าง (signed) ทุกตัวเริ่มที่ 0 = ปัจจุบัน ยกเว้น auctionBtc ค่าสัมบูรณ์ default 2.5 (1.8..3.2)
3. **ช่วง/ขั้น: ยึดต้นฉบับเป๊ะ** — fedBps −200..200/25, oilPct −40..60/5, goldPct −20..40/5, vixPts −10..30/1, hyBps −100..400/25, cpiPts −2..3/.25, depositPct −3..1/.25, dwBillion 0..100/5, sofrSpreadBps 0..100/5, debtPts 0..20/1, auctionBtc 1.8..3.2/.1
4. **ตัวแปรพันกัน: คำนวณแบบต่อเนื่อง** — fedBps → us10y/us2y/curve พร้อมกัน (us10y += fedBps/100×0.5, us2y += fedBps/100 เหมือน h() ต้นฉบับ); goldPct → gold_chg_pct + xauusd; depositPct → เงินฝาก WoW
5. **available=false: ตามต้นฉบับ** — เปิดลากทุกตัว + fallback ค่ากลางต้นฉบับ (us10y 4.2, us2y 3.8, vix 18, oil 70, HY 300, CPI 3) + warning เหลือง "⚠️ ไม่มีค่าฐานสดของ … — ใช้ค่ากลางแทน"
6. **Preset: เพิ่ม 5 อันออกแบบเอง** — น้ำมันช็อก / เฟดช็อก / วิกฤตเครดิต / เงินฝากไหลออก / รีเฟลชัน (ต่างจากต้นฉบับที่ไม่มี preset)
7. **ปุ่มรีเซ็ต: มี** + แสดงค่าจริงปัจจุบันใต้ slider ตลอด + disclaimer "การจำลองเป็นค่าประมาณทิศทางจากตรรกะเดียวกับ scoring engine (แบบย่อ) — ไม่ใช่ผลการคำนวณเต็มรูปแบบ"

## Question

ผู้ใช้จะปรับ**อะไร**ได้บ้าง และปรับ**ยังไง**?

ticket 01 บอกว่าต้นฉบับเปิดอะไร ticket 02 บอกว่าของเราตัวไหนขยับคะแนนจริง — ticket นี้เอาสองอันมาชนกันแล้วให้ user ตัดสิน

## ตัวเลือกที่ต้องตัดสินใจ (ถาม user ทีละข้อ ตาม /grilling)

1. **ชุดตัวแปร** — เอาตามต้นฉบับเป๊ะ (ตาม decision "มิเรอร์ 100% เท่าที่ทำได้") หรือใช้ผลจาก ticket 02 คัดเฉพาะตัวที่ขยับคะแนนเราจริง? สามกรณีที่ต้องแยกให้ user เห็น:
   - ต้นฉบับมี **และ** ของเราขยับ → เปิดแน่นอน
   - ต้นฉบับมี **แต่** ของเราไม่ขยับ (ไม่มี scorer) → เปิดแล้วลากแล้วนิ่ง = ดูเหมือนพัง / ปิด = ไม่มิเรอร์ / เพิ่ม scorer = ขยาย scope เข้า engine
   - ต้นฉบับไม่มี **แต่** ของเราขยับแรง → เพิ่มเข้าไปเกินต้นฉบับไหม
2. **ค่าสัมบูรณ์ หรือ ส่วนต่าง** — ลาก VIX ไปที่ 40 หรือ ลาก VIX +25 จากปัจจุบัน? (ส่วนต่างสื่อ "จำลองการเปลี่ยนแปลง" ตรงกับชื่อ tab กว่า แต่ค่าสัมบูรณ์อ่านง่ายกว่าเมื่อเทียบกับข่าวจริง) ต้นฉบับทำแบบไหน
3. **ช่วงค่าและขั้น** — ของแต่ละตัวแปร ยึดต้นฉบับหรือกำหนดเองจากช่วงที่เกิดขึ้นจริงในประวัติศาสตร์
4. **ตัวแปรที่พันกัน** (จากหมอกในแผนที่ + ผล ticket 02) — ลาก `us10y` แล้ว `curve_10y2y_bps` ควรขยับตามอัตโนมัติไหม หรือปล่อยให้ผู้ใช้สร้างสภาวะที่เป็นไปไม่ได้ (10y ตก แต่ curve ชันขึ้น พร้อมกัน)
5. **ตัวแปรที่ `available=false`** — เปิดให้ลากไหม
6. **Preset scenarios** — มีไหม ถ้ามี ชื่อไทยว่าอะไร ตั้งค่าอะไรบ้าง เอาตามต้นฉบับหรือออกแบบเองให้เข้ากับ 6 โมเดลของเรา
7. **ปุ่มรีเซ็ต** — กลับค่าปัจจุบันทั้งหมดด้วยคลิกเดียวไหม
