## Question

เทิร์นเทรดหนึ่งครั้งใช้เงินเท่าไหร่ และ**สองทีมตัดสินใจต่างกันจริงไหม**เมื่อได้ข้อมูลชุดเดียวกัน?

user ตัดสิน 2026-08-09: **ต้องมี ticket วัดต้นทุนจริงก่อน** — ใบนี้คือประตูที่แผนต้องผ่าน

## คำถามที่แพงกว่าเงิน

ทั้งฟีเจอร์ตั้งอยู่บนสมมติฐานว่า **AI สองทีมจะตัดสินใจต่างกัน** ถ้ารันจริงแล้วทั้งสองทีมเปิดไม้เหมือนกันทุกครั้ง (ซึ่งเป็นไปได้สูงเพราะเป็นโมเดลเดียวกัน prompt ต่างกันเล็กน้อย) — การแข่งขันจะไม่มีความหมาย และไม่มีเหตุผลจะสร้างสองทีมตั้งแต่แรก

ticket นี้ต้องตอบให้ได้ว่าสมมติฐานนั้นจริงหรือไม่ **ก่อน**เขียนเครื่องยนต์

## สิ่งที่ต้องทำ

สคริปต์ทิ้งได้ที่ `.scratch/trade-desk/prototype-03/` — **ยังไม่ใช่โค้ด production**

1. ป้อนสถานการณ์ตลาดจริงจากแอป (macro dashboard + model scores + ราคาจริง + ข่าวล่าสุด) — ห้ามใช้ข้อมูลสมมติ
2. รันเทิร์นตัดสินใจของ**ทั้งสองทีม**ตามผัง ticket 02 ด้วย DeepSeek จริง
3. **นับให้ครบ**: คอล, tokens_in, tokens_out, เวลา, ค่าใช้จ่ายจริงเป็นเงิน (อ้างอิงเรตจากหน้า pricing ของ DeepSeek พร้อมวันที่)
4. **รันซ้ำอย่างน้อย 5 เทิร์นด้วยสถานการณ์ต่างกัน** — เทิร์นเดียวบอกอะไรไม่ได้

## สิ่งที่ต้องเอาให้ user ตัดสิน (HITL — ห้ามตัดสินเอง)

1. **ต้นทุนต่อเทิร์น** + ประมาณการต่อวัน/ต่อเดือนตามจังหวะที่ ticket 02 เลือก → user กำหนดเพดาน
2. **อัตราการตัดสินใจต่างกัน** — จาก 5 เทิร์น สองทีมเปิดไม้ต่างกันกี่ครั้ง? ถ้าเหมือนกันเกิน 4/5 ให้เสนอ user ตรงๆ ว่าสมมติฐานไม่ผ่าน
3. **เหตุผลที่แต่ละทีมให้** — อ่านแล้วรู้สึกว่าเป็นคนละกลยุทธ์จริง หรือเป็นข้อความเดียวกันคนละสำนวน
4. **มันแต่งตัวเลขไหม** — ตรวจทุกราคา/ตัวเลขในเหตุผลว่าตรงกับที่ป้อนเข้าไป (หลักห้ามละเมิดข้อ 2)
5. **ออเดอร์ที่ออกมาสมเหตุสมผลไหม** — ขนาดไม้ กับ SL/TP อยู่ในกรอบที่รับได้ หรือมันเปิดไม้ใหญ่เกินพอร์ตทุกครั้ง

## เกณฑ์ตัดสิน (ตกลงกับ user ก่อนรัน)

ถ้าสองทีมตัดสินใจเหมือนกันเกือบทุกครั้ง ทางเลือกคือ (ก) แก้ prompt ให้ต่างขึ้นแล้วรันใหม่ (ข) ลดเหลือทีมเดียวแล้วเปลี่ยนฟีเจอร์เป็น "พอร์ตจำลอง AI" ไม่ใช่การแข่งขัน (ค) ล้มเลิก — **อย่าฝืนสร้างการแข่งขันที่พิสูจน์แล้วว่าไม่มีการแข่งขันจริง** (บทเรียนจากแผน ai-signal-upgrade ที่ทิ้งคะแนนความเชื่อมั่นเดิมหลัง backtest พบว่าไม่มีค่าทำนาย)

## เป้าหมาย

ตัวเลขต้นทุนจริง + หลักฐานว่าสองทีมต่างกันจริงหรือไม่ + คำตัดสินของ user → `## Answer` → ปลดบล็อก ticket 06
