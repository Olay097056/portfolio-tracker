# Adopt stockvision-app's visual theme instead of the Variant A gold/dark theme

Variant A (fixed 3-column trading-terminal layout, gold/dark theme) was chosen from the dashboard prototype but never wired into the real app (`theme.css` sat unused). The user separately drafted a standalone app, stockvision-app, with its own visual language (radial-gradient background, glass/glow cards, blue `#38bdf8` primary + purple `#8b5cf6` accent, Inter/Outfit fonts via Google Fonts). When merging stockvision-app's features into portfolio-tracker, the user chose to keep Variant A's structural layout (3-column dashboard + separate Portfolios page) but replace its color/style tokens entirely with stockvision-app's, because they prefer stockvision-app's look. `theme.css`'s gold-based palette is superseded and will not be used. The rebalance-severity colors (green/yellow/red) are kept as the semantic signal per PRD section 8, re-shaded to fit the new palette rather than dropped.
