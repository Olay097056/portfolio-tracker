## Question

ทีมเทรดอะไรได้บ้าง ราคามาจากไหน และเราจะมั่นใจได้ยังไงว่ามันไม่มีทางส่งคำสั่งจริงออกไป?

## ⚠️ ข้อนี้ไม่ใช่ความชอบ — เป็นกฎความปลอดภัย

ต้นฉบับใช้ราคาจาก **Hyperliquid** ซึ่งเป็นกระดานเทรด perpetual จริง มี API ที่ส่งคำสั่งได้ **แผนนี้บังคับว่า PAPER ONLY** (หลักห้ามละเมิดข้อ 1): ดึงราคาได้ แต่ห้ามมี API key ที่ส่งคำสั่งได้ · ห้ามต่อบัญชีจริง · ห้ามมีเส้นทางโค้ดที่ยิงออเดอร์ออกไปได้เลย

ticket นี้ต้องออกแบบ**กำแพง**ให้ชัด ไม่ใช่แค่ตั้งใจว่าจะไม่ทำ

## ข้อเท็จจริงตั้งต้น (แหล่งราคาที่เรามีอยู่แล้ว)

| กลุ่ม | แหล่ง | ความสด | สถานะ |
|---|---|---|---|
| หุ้น/ETF/ดัชนี/ทอง/น้ำมัน/FX | yfinance | ระหว่างวัน | ใช้อยู่แล้ว |
| ยีลด์/สเปรด US | FRED ผ่าน `macro_service` | รายวัน | ใช้อยู่แล้ว |
| คริปโต (perp) | **ไม่มี** | — | ต้องเพิ่มถ้าจะรองรับ |

## ตัวเลือกที่ต้องตัดสินใจ (ถาม user ทีละข้อ)

1. **สินทรัพย์ที่ทีมเทรดได้** — (ก) ใช้ของที่เรามีอยู่แล้ว (หุ้น/ETF/ทอง/น้ำมัน/FX ผ่าน yfinance) ไม่ต้องเพิ่มแหล่งใหม่ (ข) เพิ่มคริปโตให้เหมือนต้นฉบับ ต้องหาแหล่งราคาใหม่ — ความเห็นตั้งต้น: **(ก)** เพราะไม่ต้องพึ่งแหล่งใหม่ และตรงกับข้อมูลที่โมเดล 6 ตัวของเราวิเคราะห์อยู่แล้ว
2. **ถ้าเลือก (ข) จะดึงราคาคริปโตจากไหน** — Hyperliquid มี public info API (อ่านอย่างเดียว) ไหม? ticket 01 ข้อ 10 ตอบไว้แล้ว — ถ้าต้องใช้คีย์ที่มีสิทธิ์เทรดด้วย **ให้ตัดทิ้งทันที** ไม่ต่อรอง
3. **รายการสินทรัพย์ตายตัวหรืออิสระ** — บังคับ AI ให้เลือกจากรายการที่เราดึงราคาได้เท่านั้น (แนะนำ) หรือปล่อยอิสระแล้วเสี่ยงได้ไม้ที่ตีราคาไม่ได้
4. **กำแพงกันเทรดจริง — ออกแบบยังไงให้ตรวจสอบได้** เสนอทางเลือกให้ user เลือกอย่างน้อยหนึ่งอย่าง:
   - เก็บ**ทุกออเดอร์ในตารางของเราเท่านั้น** ไม่มี client ที่ส่งคำสั่งได้อยู่ในโค้ดเลย
   - ห้าม import ไลบรารี exchange client ใดๆ เข้าโปรเจค
   - เทสต์ที่ยืนยันว่าไม่มี outbound request ไปยัง endpoint ที่ส่งคำสั่งได้
   - ถ้าต้องใช้คีย์ API ใดๆ ต้องเป็นคีย์ read-only เท่านั้น และบันทึกไว้ใน spec ว่าใครออกให้และสิทธิ์อะไร
5. **ความสดของราคาที่ต่างกัน** — ถ้าทีมเทรดทั้งหุ้น (ระหว่างวัน) และยีลด์ (รายวัน) การคิด P&L สองกลุ่มจะไม่เท่ากัน จะแสดงยังไงให้ซื่อสัตย์
6. **ตลาดปิด/วันหยุด** — ทีมเปิดไม้ตอนตลาดปิดได้ไหม ใช้ราคาไหน (ราคาปิดล่าสุด = สมจริงพอ / ห้ามเทรดตอนปิด = สมจริงกว่าแต่ซับซ้อนกว่า)
7. **ราคาดึงไม่ได้ตอนต้องตัดสินใจ** — ข้ามเทิร์น / ใช้ราคาล่าสุดพร้อมป้ายบอก / ปิดไม้ — ห้ามแต่งราคา (หลักห้ามละเมิดข้อ 2)
